# 📸 Fotos a PDF (App Web)

Convierte fácilmente imágenes desde tu dispositivo en un único archivo PDF. Esta app funciona en navegador y también puede instalarse como PWA.

## 🚀 Funcionalidades

- Subir múltiples imágenes (JPG, PNG)
- Previsualización de las fotos
- Generar un PDF descargable
- App web responsiva e instalable (PWA-ready)

## 🛠️ Cómo desplegar en Vercel

1. Clona este repositorio o súbelo a GitHub
2. Ve a [https://vercel.com](https://vercel.com) > "Add New Project"
3. Elige este repositorio
4. En **Framework Preset**, elige `Other`
5. En **Output Directory**, escribe: `.`
6. Haz clic en **Deploy**

## 📄 Librerías usadas

- [jsPDF](https://github.com/parallax/jsPDF) para crear el archivo PDF
